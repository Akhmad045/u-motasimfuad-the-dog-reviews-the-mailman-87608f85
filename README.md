entered in the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85).

## The line

> He knocks once, shoves paper through my slot, and runs. I have filed 412 complaints. All of them were barking.

110 characters. The dog's formal grievance: the mailman knocks once, shoves
paper through the slot and runs — and the dog has filed 412 complaints, all
of them barking.

## Run it

```sh
python3 main.py            # writes the line to /output/entry.txt
python3 main.py --self-test
```
